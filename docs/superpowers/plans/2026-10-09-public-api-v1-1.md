# Public API v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Limits per API key, the IP allow-list in the user's profile, a trade-link check route, Steam offer id / seller name in `trade`, a 30-minute alert for API orders in `buying` (with Alertmanager live), and the docs — all additive to `/api/v1/public`.

**Architecture:** Four nullable limit columns on `api_keys` read by `public_api/limits.py`; a site route and a profile block for the allow-list; the site's trade-link checker reused behind a new public route; two new fields computed in `orders/public_view.py`; a gauge set by the scheduler's `orders.health` job and an alert rule; Alertmanager moved to its own compose profile.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2 async, Alembic, Pydantic v2, pytest + testcontainers; Next.js 15 + next-intl (web), Vite + React 19 + TanStack Query (admin), Vitest; Prometheus rules; docker compose.

**Spec:** `docs/superpowers/specs/2026-10-09-public-api-v1-1-design.md`

## Global Constraints

- Only fields and routes are added; existing v1 clients keep working; path stays `/api/v1/public`.
- Default limits per minute: read 60, order 10, feed 1, check 30. A key column `NULL` = the default; DB `CHECK (x IS NULL OR x > 0)`; admin input `null` or 1–10 000.
- Limits and the IP allow-list carry over on key reissue, like `pricing_profile`.
- IP allow-list: IPv4 / IPv6 address or CIDR, normalised with `ipaddress.ip_network(strict=False)`, deduplicated, at most 20; empty = any; a bad entry → 422 `ip_allowlist_invalid` naming its index.
- Trade-link check: `POST /api/v1/public/tradelink/check`, body `{"trade_link": str ≤ 512}`, answer `{"verdict": "ok"|"bad"|"unavailable", "reason": "invalid_link"|"private_inventory"|"trade_ban"|"hold"|"not_found"|null}`; no `Idempotency-Key`; bucket `check`; an unparsable link → `bad`/`invalid_link` with no upstream call.
- Metric `csmarket_public_api_orders_buying_oldest_seconds` (gauge, no labels); alert `PublicApiOrderBuyingLong` at `> 1800` for 5m, severity `warn`.
- Never log a trade-link token or an allow-list address; never print real keys or links in tests/docs (use `partner=1&token=FAKEFAKE`-style fakes).
- Python: ruff (line 100), mypy --strict, Google docstrings, no `Any` without a comment, files ≤ 400 LOC soft. TS: strict, no `any`, all user-facing strings in ru / uz / en.
- `scripts/check-no-yupay.sh` bans `supplier`, `sku`, `yupay` etc. in `src` (only `supplier_refused` is allowed).
- Commit per task, Conventional Commits, header ≤ 100 chars, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push.
- Tests: run only the touched files locally (`cd apps/api && uv run pytest <files> -p no:xdist --no-cov -q`); integration tests need Docker (testcontainers). Web/admin: `pnpm --filter <pkg> exec vitest run <file>`.
- Prettier only from the repo root (`npx prettier --write <paths>`); never on `docs/api/openapi.json` or `infra/docs-site/*.json`.

## Review Focus

1. A reissued key after an admin raised its limits: the new key must keep 600, not fall back to 60 (Task 1 test `test_reissue_carries_limits_and_allowlist`).
2. An allow-list that already blocks the user's own server: saving a corrected one through the site must still work, since the site route never reads the allow-list (Task 3 test `test_allowlist_does_not_gate_the_site_route`).
3. The trade-link check under an open breaker or a cached verdict must make no upstream call, and the `check` bucket must not eat the `read` budget (Task 4 tests).
4. `trade.steam_offer_id` must be a string even when stored numeric-looking, and `null`, not `""`, when absent (Task 5 test `test_empty_offer_id_reads_null`).
5. The gauge must count a `failed`/`returned` API order held without a refund (it reads `buying` to the partner) and ignore site orders (Task 6 test `test_gauge_counts_held_failed_and_ignores_site_orders`).

```python
"""A key's IP allow-list as the user sets it (spec v1.1 §4)."""

from __future__ import annotations

import ipaddress

from csmarket.core.errors import ValidationError

#: Entries a key may carry.
MAX_ENTRIES = 20


def normalise(entries: list[str]) -> list[str]:
    """Networks in canonical form, first occurrence kept; ``[]`` = any address.

    Raises:
        ValidationError: ``ip_allowlist_invalid`` with the ``index`` of the bad entry.
    """
    out: list[str] = []
    for index, raw in enumerate(entries):
        if index >= MAX_ENTRIES:
            raise ValidationError("too many addresses", code="ip_allowlist_invalid", index=index)
        try:
            net = str(ipaddress.ip_network(raw.strip(), strict=False))
        except ValueError:
            raise ValidationError(
                "not an IP address or network", code="ip_allowlist_invalid", index=index
            ) from None
        if net not in out:
            out.append(net)
    return out
```

```python
@router.post(
    "/tradelink/check",
    response_model=TradeLinkCheckOut,
    summary="Check a trade link before buying",
    responses=_AUTH_ERRORS,
)
async def check_trade_link_route(
    body: TradeLinkCheckIn,
    caller: Caller,
    db: Db,
    checkers: Annotated[tuple[TradelinkChecker, HoldChecker], Depends(tradelink_checkers)],
) -> TradeLinkCheckOut:
    """Whether a Steam trade can be sent to ``trade_link`` now (advisory).

    No ``Idempotency-Key``: it writes nothing and a repeat is the intended use (the verdict is
    cached 10 minutes). ``POST`` keeps the link's token out of URLs and access logs.
    ``unavailable`` means the check could not run: do not block a purchase on it.
    """
    await enforce(caller, "check")
    try:
        link = parse_tradelink(body.trade_link)
    except ValidationError:
        return TradeLinkCheckOut(verdict="bad", reason="invalid_link")
    await db.commit()  # no connection held across the upstream calls (AGENTS §11)
    waxpeer, hold = checkers
    result = await check_trade_link(link, waxpeer=waxpeer, hold=hold, redis=get_redis())
    if result.verdict is None:
        return TradeLinkCheckOut(verdict="unavailable", reason=None)
    reason = None if result.reason is None else PUBLIC_REASONS[result.reason]
    return TradeLinkCheckOut(verdict=result.verdict, reason=reason)
```
