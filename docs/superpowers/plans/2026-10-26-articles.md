# Articles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A news / guides / top-lists section the owner writes in the admin in ru / uz / en, served
on the storefront with live skin cards, views and likes, indexed by search engines.

**Architecture:** A new backend module `modules/articles` (tables, admin CRUD + publish, public
read, media, views, likes). Images live in Postgres as payout receipts do (ADR-0024), served from
`/api/v1/media/<hash>.<ext>` with an immutable cache. One Markdown renderer in `@csmarket/ui`
renders both the storefront page and the admin preview; skin embeds are resolved by the API.

**Tech Stack:** FastAPI, SQLAlchemy async, Alembic, pytest + testcontainers; Next.js 15 RSC,
next-intl; Vite + React admin, TanStack Query; new: `react-markdown`, `remark-gfm` (ADR-0025).

**Spec:** `docs/superpowers/specs/2026-10-26-articles-design.md`

## Global Constraints

- Sections `news` / `guides` / `tops`; locales `ru` / `uz` / `en`; slug `^[a-z0-9-]{3,80}$`, one per
  article, unique across `articles.slug` and `article_slugs_old.slug`.
- Limits: title ≤ 120, description ≤ 200, cover_alt ≤ 160, body ≤ 60 000 chars; image JPEG / PNG /
  WebP by magic bytes, ≤ 5 MB (5 × 1024 × 1024).
- A translation is **live** iff article `status = 'published'` AND translation `ready` AND title
  and body non-empty. Anything else answers 404 publicly.
- Publish needs a cover and ≥ 1 ready translation. No delete, only unpublish.
- Views: beacon, once per article per visitor per UTC day, dedup key
  `sha256(daily_salt + ip + article_id)`; the IP is never stored or logged.
- Likes: toggle; key `user_id` when signed in, else cookie `csm_aid` (UUID4, HttpOnly,
  SameSite=Lax, Secure in prod, max-age 1 year, domain = the API host); `ip_guard` bucket
  `article-like` = 30 per window (the guard's one 60 s window, crowd-sized like every bucket;
  the spec's «per hour» adapted).
- Markdown with raw HTML disabled; images only from our `/media/` path; links only `http(s):`,
  `mailto:` or relative; `[[skin:<slug>]]` alone on a line is the embed.
- Admin writes: `Idempotency-Key` (`required_key`, `replayed` / `remember`) and an audit row
  `articles.<verb>`; errors as `ConflictError` / `ValidationError(code=...)`.
- Author «Редакция csmarket» (`Organization`), never a person. No PII in logs.
- Copy rules (AGENTS.md §12): «вы», short sentences; all three locale catalogs in the same commit.
- `articles` joins the ≥ 95 % module coverage list in `scripts/check-module-coverage.py`.
- Revalidation: storefront reads articles with `revalidate: 60` and tag `articles` — no
  on-demand hook (deviation from the spec's «on-demand, falling back to 5 min»: a one-minute delay
  is acceptable and saves an internal webhook; noted in ADR-0025).

## Review Focus

1. **A published article whose only ready translation is unready later** (admin unticks
   «Перевод готов» on the last one) → the article stays `published` but has no live translation;
   it must vanish from lists and the sitemap, and the header link must hide if it was the last.
   Test in Task 5 (`test_unready_last_translation_hides_the_article`).
2. **An old slug requested after the slug changed twice** (A → B → C) → A and B both 301 to C,
   never to B. Test in Task 4 (`test_every_former_slug_points_to_the_current`).
3. **A skin embed whose item is hidden, delisted or has no price** → the site renders nothing
   for it (no broken card, no 500). Test in Task 5 (`test_embeds_skip_unknown_and_hidden_items`).
4. **Markdown with `<script>`, `javascript:` links or an outside image** → rendered as text /
   dropped. Test in Task 7 (`renders raw HTML as text and drops unsafe urls`).
5. **The like button pressed fast twice, or by a signed-in user who earlier liked anonymously**
   → the count never goes below zero and never double-counts one key. Test in Task 6
   (`test_like_is_idempotent_per_key`, `test_unlike_without_like_is_a_noop`).
