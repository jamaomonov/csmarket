# Reviews Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After every successful deal — a delivered order (market) or a paid sale (buy-back) — the
user gives 1–5 stars and an optional text; bad reviews reach an admin tab to be handled, good ones
appear on `/reviews` once the owner switches the public page on.

**Architecture:** A new module `reviews` owns three tables (`reviews`, `review_prompts`,
`review_settings`), a read rule (`deals.py`: rule 7, the 14-day window, the newest pending deal),
the user / public routes and the admin routes. Publication is computed (`rating >= 4 AND NOT
hidden`), never stored. The storefront mounts one site-wide controller beside the order socket:
a socket nudge re-reads `GET /reviews/pending` and opens the modal for a deal that succeeded during
this visit; on a page load it shows a bottom strip once per visit. The admin gets «Отзывы» in «Люди»
with a counter of unresolved bad reviews and the public-page switch.

**Tech Stack:** FastAPI, SQLAlchemy 2 async, Alembic, Pydantic v2, pytest + testcontainers,
prometheus_client, APScheduler; Next.js 15 + next-intl + TanStack Query (web); Vite + React 19 +
TanStack Query (admin).

**Spec:** `docs/superpowers/specs/2026-10-23-reviews-design.md`

## Global Constraints

- Work on branch `reviews` cut from local `main` (`git switch -c reviews main`). Commit locally after
  every task. **Never push, never deploy.**
- Owner rulings (spec): two kinds `market` / `sale`; **good = 4–5, bad = 1–3**; published =
  `rating >= 4 AND NOT hidden`, computed; a bad review is never published; the public page is
  **off** until the admin switch; the reminder is a bottom strip **once per visit**, «Не сейчас» =
  **3 days**, × = for good; **no prompt 14 days after the deal**; the interface locale
  (`ru` / `uz` / `en`) is recorded, the text is not language-detected.
- Rule 7: an order is reviewable at status `delivered`, from `delivered_at`; a sale to the balance at
  status `credited`, from `credited_at`; a sale to a card when its payout request is `paid`, from the
  request's `paid_at`. Reviewable (and editable) while `now − done_at ≤ 14 days`.
- One review per deal (`UNIQUE(order_id)`, `UNIQUE(sale_id)`); only the deal's owner; anything else
  is 404 `deal_not_found` (an owner's deal outside rule 7 / the window is 409 `review_not_allowed`).
- **Review text and display names are never logged** and never go into an audit payload or a metric
  label. Log kind, number and rating only. Text is trimmed, ≤ 1000 chars, stored as typed, rendered
  as text (never `dangerouslySetInnerHTML`).
- Every state-changing route takes `Idempotency-Key` (16..160 chars): the user routes through
  `require_idempotency_key` + `admin.api.replayed` / `remember` with scope
  `reviews.<verb>:<user_id>` (the scope, not the key, carries the user: the key column is
  `varchar(160)`); admin routes through `required_key`. Admin writes are audited with `record(...)`.
- `PUT /reviews/…` is rate-limited by `guard_ip(request, bucket="review", subject=user.id)`.
- Metrics: `csmarket_reviews_total{kind, rating}` (on create only) and the gauge
  `csmarket_reviews_bad_open` (set by the scheduler); **no alert**.
- Constraint names in models and migrations are bare suffixes for checks (`name="rating"`); unique
  constraints carry the full `uq_reviews_…` name (as `orders` does).
- Source under `apps/*/src` must not contain `yupay`, `supplier`, `merchant…`, `sku` (the
  `check-no-yupay` guard).
- Python: mypy --strict, Google docstrings, files ≤ 400 LOC, functions ≤ 50 LOC. TS: strict, no
  `any`, no `as` except narrowing JSON with a comment, exhaustive switches end in `assertNever`.
- All storefront strings in ru / uz / en in the same commit (`packages/i18n/locales/*/web.json`,
  namespace `web.reviews`); copy: short, «вы», outcome not mechanism. Admin copy is Russian.
- `reviews` joins the 95 % coverage list (`scripts/check-module-coverage.py`, AGENTS §9).
- Prettier only from the repo root: `npx prettier --write <files>` / `npx prettier --check .` —
  never from `apps/web` (it reformats `openapi.json`). mypy from the repo root:
  `uv run mypy <paths>` — never from `apps/api`.
- Integration tests need Docker running (testcontainers). Run a task's own tests with
  `cd apps/api && uv run pytest <files> -q`; the full suites run on CI.
- Conventional Commits with scopes `api/reviews`, `scheduler`, `web/reviews`, `admin/reviews`,
  `docs`; every message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A partner-API order is delivered** (`orders.channel = 'api'`, a bot buying through the public
   API): it must never be pending, never reviewable, never prompted. (Task 2 test
   `test_a_partner_api_order_is_never_reviewable`.)
2. **Two tabs submit the first review of one deal at once** (two different `Idempotency-Key`s): one
   row, both answers 200, no `IntegrityError` 500. (Task 3 test
   `test_two_first_reviews_at_once_make_one_row` — the deal row lock in `find_deal(lock=True)`.)
3. **Whitespace-only or HTML-looking text**: `"   "` is stored as `NULL`; `<b>hi</b>` is stored
   and shown literally, never as markup. (Task 3 test `test_text_is_trimmed_and_blank_is_null`;
   Task 11 test «renders a review's text as text».)
4. **The author's account is deleted** (`users.deleted_at`) while the page is on: the review is not
   listed and not counted in the average. (Task 4 test `test_only_published_by_live_accounts`.)
5. **After answering the live modal, an older pending deal must not pop up as a second modal**
   (the pending query re-reads after a send and returns the next older deal). (Task 9 test
   «does not open the modal for an older deal after a send».)

```python
"""SQLAlchemy ORM for ``reviews`` (spec ``2026-10-23-reviews-design.md``, ADR-0023).

- :class:`Review` — one per deal (an order or a sale): 1–5 stars, an optional plain text, the
  interface locale at submission. Published = ``rating >= 4 AND NOT hidden``, computed by
  :func:`published`, never stored.
- :class:`ReviewPrompt` — one row per deal the user answered the prompt for: «Не сейчас»
  (``snoozed_until``) or × (``dismissed``). Server-side, so it holds on every device.
- :class:`ReviewSettingsRow` — row 1: ``reviews_public``, the public page's switch.

The review text is the user's own words: never logged, never in an audit payload.
"""

from __future__ import annotations

from datetime import datetime, timedelta

from sqlalchemy import (
    Boolean,
    CheckConstraint,
    DateTime,
    ForeignKey,
    Index,
    Integer,
    SmallInteger,
    String,
    Text,
    UniqueConstraint,
    and_,
    text,
)
from sqlalchemy.dialects.postgresql import UUID
from sqlalchemy.orm import Mapped, mapped_column
from sqlalchemy.sql.elements import ColumnElement

from csmarket.core.db import Base
from csmarket.core.ids import new_id

REVIEW_KINDS = ("market", "sale")
REVIEW_LOCALES = ("ru", "uz", "en")
#: Owner ruling 2: 4–5 stars is good (published once the page is on), 1–3 bad (never).
GOOD_FROM = 4
TEXT_MAX = 1000
#: How long after the deal succeeded it may be reviewed, and its review edited.
REVIEW_WINDOW = timedelta(days=14)
#: «Не сейчас» hides the prompt for this long.
SNOOZE = timedelta(days=3)

_ONE_DEAL = "(order_id IS NULL) <> (sale_id IS NULL)"
_KIND_DEAL = "(kind = 'market') = (order_id IS NOT NULL)"


def _in(values: tuple[str, ...]) -> str:
    """``('a', 'b')`` as a SQL ``IN`` list."""
    return "(" + ", ".join(f"'{v}'" for v in values) + ")"


def _ts() -> Mapped[datetime]:
    """A ``NOT NULL`` timestamp the database fills in."""
    return mapped_column(
        DateTime(timezone=True), nullable=False, server_default=text("CURRENT_TIMESTAMP")
    )


def _deal_fk(table: str) -> Mapped[str | None]:
    """A nullable FK to ``orders`` or ``sales``: a deal is never deleted under its review."""
    return mapped_column(
        UUID(as_uuid=False), ForeignKey(f"{table}.id", ondelete="RESTRICT"), nullable=True
    )


class Review(Base):
    """One user's stars (and words) about one deal."""

    __tablename__ = "reviews"

    id: Mapped[str] = mapped_column(UUID(as_uuid=False), primary_key=True, default=new_id)
    #: One of :data:`REVIEW_KINDS`.
    kind: Mapped[str] = mapped_column(String(8), nullable=False)
    order_id: Mapped[str | None] = _deal_fk("orders")
    sale_id: Mapped[str | None] = _deal_fk("sales")
    #: The author: the deal's owner.
    user_id: Mapped[str] = mapped_column(
        UUID(as_uuid=False), ForeignKey("users.id", ondelete="RESTRICT"), nullable=False
    )
    rating: Mapped[int] = mapped_column(SmallInteger, nullable=False)
    #: As typed, trimmed; ``NULL`` when blank. Plain text: rendered as text, never logged.
    text: Mapped[str | None] = mapped_column(Text, nullable=True)
    #: The interface locale at submission (owner ruling 6).
    locale: Mapped[str] = mapped_column(String(2), nullable=False)
    #: An admin hid it from the public page.
    hidden: Mapped[bool] = mapped_column(
        Boolean, nullable=False, server_default=text("false"), default=False
    )
    #: A bad review handled by an admin («Разобрано»): when, who, what they did.
    resolved_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    resolved_by: Mapped[str | None] = mapped_column(
        UUID(as_uuid=False), ForeignKey("users.id", ondelete="SET NULL"), nullable=True
    )
    resolved_note: Mapped[str | None] = mapped_column(Text, nullable=True)
    created_at: Mapped[datetime] = _ts()
    updated_at: Mapped[datetime] = _ts()

    __table_args__ = (
        UniqueConstraint("order_id", name="uq_reviews_order_id"),
        UniqueConstraint("sale_id", name="uq_reviews_sale_id"),
        # Bare suffixes: the metadata naming convention adds ``ck_reviews_``.
        CheckConstraint(f"kind IN {_in(REVIEW_KINDS)}", name="kind"),
        CheckConstraint(f"locale IN {_in(REVIEW_LOCALES)}", name="locale"),
        CheckConstraint("rating BETWEEN 1 AND 5", name="rating"),
        CheckConstraint(
            f"text IS NULL OR char_length(text) BETWEEN 1 AND {TEXT_MAX}", name="text_len"
        ),
        CheckConstraint(_ONE_DEAL, name="one_deal"),
        CheckConstraint(_KIND_DEAL, name="kind_deal"),
        Index("ix_reviews_created_at", "created_at"),
        Index("ix_reviews_user_id", "user_id"),
        Index(
            "ix_reviews_bad_open",
            "created_at",
            postgresql_where=text("rating <= 3 AND resolved_at IS NULL"),
        ),
        Index(
            "ix_reviews_published",
            "created_at",
            postgresql_where=text("rating >= 4 AND NOT hidden"),
        ),
    )


class ReviewPrompt(Base):
    """The user's answer to the prompt for one deal: snoozed until, or dismissed for good."""

    __tablename__ = "review_prompts"

    id: Mapped[str] = mapped_column(UUID(as_uuid=False), primary_key=True, default=new_id)
    user_id: Mapped[str] = mapped_column(
        UUID(as_uuid=False), ForeignKey("users.id", ondelete="CASCADE"), nullable=False
    )
    kind: Mapped[str] = mapped_column(String(8), nullable=False)
    order_id: Mapped[str | None] = _deal_fk("orders")
    sale_id: Mapped[str | None] = _deal_fk("sales")
    #: «Не сейчас»: no prompt before this.
    snoozed_until: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    #: ×: no prompt for this deal again.
    dismissed: Mapped[bool] = mapped_column(
        Boolean, nullable=False, server_default=text("false"), default=False
    )
    updated_at: Mapped[datetime] = _ts()

    __table_args__ = (
        UniqueConstraint("order_id", name="uq_review_prompts_order_id"),
        UniqueConstraint("sale_id", name="uq_review_prompts_sale_id"),
        CheckConstraint(f"kind IN {_in(REVIEW_KINDS)}", name="kind"),
        CheckConstraint(_ONE_DEAL, name="one_deal"),
        CheckConstraint(_KIND_DEAL, name="kind_deal"),
        Index("ix_review_prompts_user_id", "user_id"),
    )


class ReviewSettingsRow(Base):
    """Row 1: whether the public page shows the published reviews (default off)."""

    __tablename__ = "review_settings"

    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    reviews_public: Mapped[bool] = mapped_column(
        Boolean, nullable=False, server_default=text("false"), default=False
    )
    updated_by: Mapped[str | None] = mapped_column(
        UUID(as_uuid=False), ForeignKey("users.id", ondelete="SET NULL"), nullable=True
    )
    updated_at: Mapped[datetime] = _ts()

    __table_args__ = (CheckConstraint("id = 1", name="singleton"),)


def published() -> ColumnElement[bool]:
    """Published = good and not hidden (spec «Data»): the one definition every query uses."""
    return and_(Review.rating >= GOOD_FROM, Review.hidden.is_(False))


def bad() -> ColumnElement[bool]:
    """1–3 stars."""
    return Review.rating < GOOD_FROM


__all__ = [
    "GOOD_FROM",
    "REVIEW_KINDS",
    "REVIEW_LOCALES",
    "REVIEW_WINDOW",
    "SNOOZE",
    "TEXT_MAX",
    "Review",
    "ReviewPrompt",
    "ReviewSettingsRow",
    "bad",
    "published",
]
```

```python
"""Which deal a user may review now (spec rule 7), and the newest one to ask about.

A deal is an order (``market``) or a sale (``sale``). It succeeded at:

- an order: status ``delivered``, placed on the site (a partner-API order is a bot's, never
  reviewed), at ``delivered_at``;
- a sale to the balance: status ``credited``, at ``credited_at``;
- a sale to a card: its payout request ``paid``, at the request's ``paid_at``.

It may be reviewed, and its review edited, until :data:`REVIEW_WINDOW` after that moment.
"""

from __future__ import annotations

from datetime import datetime
from typing import Literal

from pydantic import BaseModel, ConfigDict
from sqlalchemy import and_, case, exists, func, or_, select
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.sql.elements import ColumnElement

from csmarket.modules.orders.api import Order
from csmarket.modules.reviews.models import REVIEW_WINDOW, Review, ReviewPrompt
from csmarket.modules.sales.api import PayoutRequest, Sale, SaleItem
from csmarket.modules.skins.api import SkinItem

Kind = Literal["market", "sale"]

#: When a sale succeeded: the balance credit, or the card payout marked paid.
_SALE_DONE = case((Sale.payout_to == "balance", Sale.credited_at), else_=PayoutRequest.paid_at)
_SALE_OK = or_(
    and_(Sale.payout_to == "balance", Sale.status == "credited"),
    and_(Sale.payout_to == "card", PayoutRequest.status == "paid"),
)
_ORDER_OK = and_(Order.status == "delivered", Order.channel == "site")


class Deal(BaseModel):
    """One order or sale as the review rules see it."""

    model_config = ConfigDict(frozen=True)

    kind: Kind
    number: str
    user_id: str
    order_id: str | None
    sale_id: str | None
    #: When it succeeded (rule 7); ``None`` while it has not.
    done_at: datetime | None
    #: The skin's name; a sale's most valuable item.
    title: str
    image_url: str | None
    items: int


def reviewable(deal: Deal, at: datetime) -> bool:
    """Succeeded, at most :data:`REVIEW_WINDOW` ago (the edge itself still counts)."""
    return deal.done_at is not None and at - deal.done_at <= REVIEW_WINDOW


def editable_until(deal: Deal) -> datetime | None:
    """The last moment the deal may be reviewed; ``None`` while it has not succeeded."""
    return deal.done_at + REVIEW_WINDOW if deal.done_at is not None else None


async def find_deal(
    db: AsyncSession, kind: Kind, number: str, *, lock: bool = False
) -> Deal | None:
    """The deal ``number`` of ``kind``, whoever owns it; ``None`` when there is none.

    ``lock`` takes the order's or the sale's row lock, so two first reviews of one deal queue
    up instead of racing the unique constraint.
    """
    if kind == "market":
        return await _find_order(db, number, lock=lock)
    return await _find_sale(db, number, lock=lock)


async def _find_order(db: AsyncSession, number: str, *, lock: bool) -> Deal | None:
    q = select(Order).where(Order.number == number)
    order = await db.scalar(q.with_for_update() if lock else q)
    if order is None:
        return None
    image = await db.scalar(select(SkinItem.image_url).where(SkinItem.id == order.skin_item_id))
    ok = order.status == "delivered" and order.channel == "site"
    return Deal(
        kind="market",
        number=order.number,
        user_id=order.user_id,
        order_id=order.id,
        sale_id=None,
        done_at=order.delivered_at if ok else None,
        title=order.market_hash_name,
        image_url=image,
        items=1,
    )


async def _find_sale(db: AsyncSession, number: str, *, lock: bool) -> Deal | None:
    q = select(Sale).where(Sale.number == number)
    sale = await db.scalar(q.with_for_update() if lock else q)
    if sale is None:
        return None
    if sale.payout_to == "balance":
        done = sale.credited_at if sale.status == "credited" else None
    else:
        request = await db.scalar(select(PayoutRequest).where(PayoutRequest.sale_id == sale.id))
        done = request.paid_at if request is not None and request.status == "paid" else None
    first = (
        await db.execute(
            select(SaleItem.name, SaleItem.image_url)
            .where(SaleItem.sale_id == sale.id)
            .order_by(SaleItem.price_uzs.desc(), SaleItem.asset_id)
            .limit(1)
        )
    ).first()
    count = await db.scalar(select(func.count()).where(SaleItem.sale_id == sale.id))
    return Deal(
        kind="sale",
        number=sale.number,
        user_id=sale.user_id,
        order_id=None,
        sale_id=sale.id,
        done_at=done,
        title=first.name if first is not None else "",
        image_url=first.image_url if first is not None else None,
        items=int(count or 0),
    )


def _muted(at: datetime) -> ColumnElement[bool]:
    """The user said × for good, or «Не сейчас» and the 3 days are not over."""
    return or_(ReviewPrompt.dismissed.is_(True), ReviewPrompt.snoozed_until > at)


async def pending_for(db: AsyncSession, user_id: str, at: datetime) -> Deal | None:
    """The newest deal of ``user_id`` to ask about now: reviewable, within the window, with no
    review, not dismissed and not snoozed. ``None`` when there is none."""
    since = at - REVIEW_WINDOW
    order_q = (
        select(Order.number, Order.delivered_at.label("done"))
        .where(
            Order.user_id == user_id,
            _ORDER_OK,
            Order.delivered_at >= since,
            ~exists().where(Review.order_id == Order.id),
            ~exists().where(ReviewPrompt.order_id == Order.id, _muted(at)),
        )
        .order_by(Order.delivered_at.desc())
        .limit(1)
    )
    sale_q = (
        select(Sale.number, _SALE_DONE.label("done"))
        .outerjoin(PayoutRequest, PayoutRequest.sale_id == Sale.id)
        .where(
            Sale.user_id == user_id,
            _SALE_OK,
            _SALE_DONE >= since,
            ~exists().where(Review.sale_id == Sale.id),
            ~exists().where(ReviewPrompt.sale_id == Sale.id, _muted(at)),
        )
        .order_by(_SALE_DONE.desc())
        .limit(1)
    )
    market: Kind = "market"
    sale: Kind = "sale"
    found: list[tuple[datetime, Kind, str]] = []
    found.extend((r.done, market, r.number) for r in (await db.execute(order_q)).all())
    found.extend((r.done, sale, r.number) for r in (await db.execute(sale_q)).all())
    if not found:
        return None
    _, kind, number = max(found)
    return await find_deal(db, kind, number)


__all__ = ["Deal", "Kind", "editable_until", "find_deal", "pending_for", "reviewable"]
```

```python
"""Wire models of ``/reviews*`` (the user and the public page) and ``/admin/reviews*``.

Dates are ISO 8601 UTC. A public or admin review carries ``kind`` / ``locale`` as plain strings
(``market`` / ``sale``, ``ru`` / ``uz`` / ``en``): they are read back from checked columns.
"""

from __future__ import annotations

from datetime import datetime
from typing import Literal

from pydantic import BaseModel, Field, field_validator

from csmarket.modules.reviews.models import TEXT_MAX

KindOut = Literal["market", "sale"]
LocaleIn = Literal["ru", "uz", "en"]


def _trimmed(value: object) -> object:
    """A string trimmed, blank as ``None``; anything else as given (Pydantic reports it)."""
    if isinstance(value, str):
        return value.strip() or None
    return value


class ReviewIn(BaseModel):
    """Stars, an optional text and the interface locale the user wrote in."""

    rating: int = Field(ge=1, le=5)
    #: Trimmed before the length check; blank is no text. Stored as typed, shown as text.
    text: str | None = Field(default=None, max_length=TEXT_MAX)
    locale: LocaleIn

    @field_validator("text", mode="before")
    @classmethod
    def _trim(cls, value: object) -> object:
        """Trim first, so trailing spaces never push a text over the limit."""
        return _trimmed(value)


class DealOut(BaseModel):
    """The deal the prompt asks about."""

    kind: KindOut
    number: str
    #: The skin's name; for a sale, its most valuable item.
    title: str
    image_url: str | None
    #: How many items (1 for an order).
    items: int
    #: When the deal succeeded (rule 7).
    done_at: datetime


class PendingOut(BaseModel):
    """The newest deal to review now, or ``null``."""

    deal: DealOut | None


class MyReviewOut(BaseModel):
    """My review as I wrote it."""

    rating: int
    text: str | None
    locale: str
    created_at: datetime
    updated_at: datetime


class DealReviewOut(BaseModel):
    """A deal of mine and my review of it."""

    kind: KindOut
    number: str
    #: It may be reviewed (or the review edited) now.
    can_review: bool
    #: The last moment it may be; ``null`` while the deal has not succeeded.
    editable_until: datetime | None
    review: MyReviewOut | None
```

`apps/api/src/csmarket/modules/reviews/service.py`:

```python
"""A user's review of their own deal: write, read, and the prompt's «Не сейчас» / ×.

Every write locks the deal's row first (``find_deal(lock=True)``), so two first reviews of one
deal from two tabs queue up and the second edits the first. Flushes, never commits. Logs the
kind, number and rating only — never the text.
"""

from __future__ import annotations

from datetime import datetime

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from csmarket.core.errors import ConflictError, NotFoundError
from csmarket.core.logging import get_logger
from csmarket.core.metrics import record_review
from csmarket.modules.reviews.deals import (
    Deal,
    Kind,
    editable_until,
    find_deal,
    pending_for,
    reviewable,
)
from csmarket.modules.reviews.models import GOOD_FROM, SNOOZE, Review, ReviewPrompt
from csmarket.modules.reviews.schemas import (
    DealOut,
    DealReviewOut,
    MyReviewOut,
    PendingOut,
    ReviewIn,
)

log = get_logger("csmarket.reviews")


async def _owned(
    db: AsyncSession, user_id: str, kind: Kind, number: str, *, lock: bool = False
) -> Deal:
    """The deal if it is ``user_id``'s; 404 otherwise (another's deal reads as no deal)."""
    deal = await find_deal(db, kind, number, lock=lock)
    if deal is None or deal.user_id != user_id:
        raise NotFoundError("no such deal", code="deal_not_found")
    return deal


def _allowed(deal: Deal, at: datetime) -> None:
    """409 ``review_not_allowed`` outside rule 7 or the 14 days."""
    if not reviewable(deal, at):
        raise ConflictError("this deal cannot be reviewed now", code="review_not_allowed")


async def review_of(db: AsyncSession, deal: Deal) -> Review | None:
    """The deal's review, if written."""
    if deal.order_id is not None:
        return await db.scalar(select(Review).where(Review.order_id == deal.order_id))
    return await db.scalar(select(Review).where(Review.sale_id == deal.sale_id))


def _out(deal: Deal, review: Review | None, at: datetime) -> DealReviewOut:
    mine = (
        None
        if review is None
        else MyReviewOut(
            rating=review.rating,
            text=review.text,
            locale=review.locale,
            created_at=review.created_at,
            updated_at=review.updated_at,
        )
    )
    return DealReviewOut(
        kind=deal.kind,
        number=deal.number,
        can_review=reviewable(deal, at),
        editable_until=editable_until(deal),
        review=mine,
    )


async def deal_review(
    db: AsyncSession, *, user_id: str, kind: Kind, number: str, at: datetime
) -> DealReviewOut:
    """My deal and my review of it. Raises 404 ``deal_not_found``."""
    deal = await _owned(db, user_id, kind, number)
    return _out(deal, await review_of(db, deal), at)


def _edit(review: Review, body: ReviewIn, at: datetime) -> None:
    """Apply an edit. A changed review that is bad afterwards is reopened (unresolved): good →
    bad (spec), and a resolved bad review the user rewrote, so an admin sees it again."""
    changed = (review.rating, review.text) != (body.rating, body.text)
    if changed and body.rating < GOOD_FROM:
        review.resolved_at = review.resolved_by = review.resolved_note = None
    review.rating, review.text, review.locale = body.rating, body.text, body.locale
    review.updated_at = at


async def save_review(
    db: AsyncSession, *, user_id: str, kind: Kind, number: str, body: ReviewIn, at: datetime
) -> DealReviewOut:
    """Write or edit my review of my deal. Flushes.

    Raises:
        NotFoundError: ``deal_not_found``.
        ConflictError: ``review_not_allowed``.
    """
    deal = await _owned(db, user_id, kind, number, lock=True)
    _allowed(deal, at)
    review = await review_of(db, deal)
    if review is None:
        review = Review(
            kind=deal.kind,
            order_id=deal.order_id,
            sale_id=deal.sale_id,
            user_id=user_id,
            rating=body.rating,
            text=body.text,
            locale=body.locale,
            created_at=at,
            updated_at=at,
        )
        db.add(review)
        record_review(deal.kind, body.rating)
    else:
        _edit(review, body, at)
    await db.flush()
    log.info("reviews.saved", kind=deal.kind, number=deal.number, rating=body.rating)
    return _out(deal, review, at)


async def _prompt(db: AsyncSession, deal: Deal) -> ReviewPrompt:
    """The deal's prompt row, added when missing (the deal row is locked by the caller)."""
    if deal.order_id is not None:
        q = select(ReviewPrompt).where(ReviewPrompt.order_id == deal.order_id)
    else:
        q = select(ReviewPrompt).where(ReviewPrompt.sale_id == deal.sale_id)
    row = await db.scalar(q)
    if row is None:
        row = ReviewPrompt(
            user_id=deal.user_id, kind=deal.kind, order_id=deal.order_id, sale_id=deal.sale_id
        )
        db.add(row)
    return row


async def snooze(db: AsyncSession, *, user_id: str, kind: Kind, number: str, at: datetime) -> None:
    """«Не сейчас»: no prompt for this deal for :data:`SNOOZE`. Flushes."""
    deal = await _owned(db, user_id, kind, number, lock=True)
    _allowed(deal, at)
    row = await _prompt(db, deal)
    row.snoozed_until, row.updated_at = at + SNOOZE, at
    await db.flush()


async def dismiss(db: AsyncSession, *, user_id: str, kind: Kind, number: str, at: datetime) -> None:
    """×: no prompt for this deal again (the account page still offers it). Flushes."""
    deal = await _owned(db, user_id, kind, number, lock=True)
    _allowed(deal, at)
    row = await _prompt(db, deal)
    row.dismissed, row.updated_at = True, at
    await db.flush()


async def pending(db: AsyncSession, *, user_id: str, at: datetime) -> PendingOut:
    """The deal the prompt asks about now, or none."""
    deal = await pending_for(db, user_id, at)
    if deal is None or deal.done_at is None:
        return PendingOut(deal=None)
    return PendingOut(
        deal=DealOut(
            kind=deal.kind,
            number=deal.number,
            title=deal.title,
            image_url=deal.image_url,
            items=deal.items,
            done_at=deal.done_at,
        )
    )
```

```python
Routers parse and dispatch: the rule is :mod:`.deals`, the writes :mod:`.service`. Every write
takes an ``Idempotency-Key``; the replay scope carries the user (``reviews.<verb>:<user id>``),

from __future__ import annotations

from typing import Annotated, Literal

async def put_review(
    kind: Kind,
    number: Number,
    body: ReviewIn,
    request: Request,
    user: Me,
    db: Db,
    idempotency_key: Key = None,
) -> DealReviewOut:
    """1–5 stars, an optional text (≤ 1000 after trimming) and the interface locale.

    ``Idempotency-Key`` (16..160) is required; a replay answers the stored review, a key reused
    for another body is 409 ``idempotency_mismatch``.
    """
    key = require_idempotency_key(idempotency_key)
    user_id = user.id
    await guard_ip(request, bucket="review", subject=user_id)
    scope = f"reviews.put:{user_id}"
    asked: dict[str, object] = {"kind": kind, "number": number, **body.model_dump()}
    if (hit := await replayed(db, scope=scope, key=key, request=asked)) is not None:
        return DealReviewOut.model_validate(hit)
    out = await service.save_review(
        db, user_id=user_id, kind=kind, number=number, body=body, at=now()
    )
    await remember(db, scope=scope, key=key, request=asked, response=out.model_dump(mode="json"))
    await db.commit()
    return out


async def _answer(
    db: AsyncSession, *, verb: Literal["snooze", "dismiss"], user_id: str, kind: Kind,
    number: str, key: str,
) -> Response:
    scope = f"reviews.{verb}:{user_id}"
    asked: dict[str, object] = {"kind": kind, "number": number}
    if await replayed(db, scope=scope, key=key, request=asked) is None:
        act = service.snooze if verb == "snooze" else service.dismiss
        await act(db, user_id=user_id, kind=kind, number=number, at=now())
        await remember(db, scope=scope, key=key, request=asked, response={})
        await db.commit()
    return Response(status_code=204)
```

`apps/api/src/csmarket/modules/reviews/cursor.py`:

```python
"""A keyset cursor over ``(rank ASC, created_at DESC, id DESC)``.

``rank`` puts one group first (the visitor's locale on the public page, unresolved bad reviews
in the admin's «Плохие»); within a group, newest first. The token is the last row's three keys,
JSON then base64url without padding; a token this module did not issue is 422 ``cursor``.
"""

from __future__ import annotations

import base64
import binascii
import json
import uuid
from datetime import datetime
from typing import NamedTuple

from sqlalchemy import SQLColumnExpression, and_, or_
from sqlalchemy.sql.elements import ColumnElement

from csmarket.core.errors import ValidationError


class RankCursor(NamedTuple):
    """The last row of a page."""

    rank: int
    at: datetime
    row_id: str


def encode_rank_cursor(rank: int, at: datetime, row_id: str) -> str:
    """The opaque token for the page after the row ``(rank, at, row_id)``."""
    raw = json.dumps([rank, at.isoformat(), row_id], separators=(",", ":")).encode()
    return base64.urlsafe_b64encode(raw).decode().rstrip("=")


def decode_rank_cursor(token: str) -> RankCursor:
    """Inverse of :func:`encode_rank_cursor`.

    Raises:
        ValidationError: ``code="cursor"`` — not a token this module issued.
    """
    try:
        padded = token + "=" * (-len(token) % 4)
        rank, stamp, row_id = json.loads(base64.urlsafe_b64decode(padded).decode())
        return RankCursor(int(rank), datetime.fromisoformat(stamp), str(uuid.UUID(row_id)))
    except (binascii.Error, ValueError, UnicodeDecodeError, TypeError, AttributeError) as exc:
        raise ValidationError("invalid cursor", code="cursor") from exc


def after(
    rank: SQLColumnExpression[int],
    at: SQLColumnExpression[datetime],
    row_id: SQLColumnExpression[str],
    c: RankCursor,
) -> ColumnElement[bool]:
    """Rows after ``c`` in ``rank ASC, at DESC, id DESC`` order."""
    return or_(
        rank > c.rank,
        and_(rank == c.rank, or_(at < c.at, and_(at == c.at, row_id < c.row_id))),
    )


__all__ = ["RankCursor", "after", "decode_rank_cursor", "encode_rank_cursor"]
```

```python
"""Row 1 of ``review_settings``: whether the public page shows reviews (default off).

No cache: one primary-key read per public request; an admin's switch shows at once (the
storefront's own data cache keeps a page for up to 5 minutes).
"""

from __future__ import annotations

from sqlalchemy.ext.asyncio import AsyncSession

from csmarket.core.clock import now
from csmarket.modules.reviews.models import ReviewSettingsRow


async def settings_row(db: AsyncSession) -> ReviewSettingsRow | None:
    """Row 1, read fresh."""
    return await db.get(ReviewSettingsRow, 1, populate_existing=True)


async def reviews_public(db: AsyncSession) -> bool:
    """The switch; off when the row is missing."""
    row = await settings_row(db)
    return row is not None and row.reviews_public


async def save_reviews_public(
    db: AsyncSession, *, value: bool, admin_id: str
) -> ReviewSettingsRow:
    """Upsert row 1; flushes, never commits."""
    row = await settings_row(db)
    if row is None:
        row = ReviewSettingsRow(id=1, reviews_public=value, updated_by=admin_id, updated_at=now())
        db.add(row)
    else:
        row.reviews_public, row.updated_by, row.updated_at = value, admin_id, now()
    await db.flush()
    return row


__all__ = ["reviews_public", "save_reviews_public", "settings_row"]
```

```python
"""The public page's reviews: published (``rating >= 4 AND NOT hidden``) and by an account
that still exists, the visitor's locale first, newest first, 20 a page."""

from __future__ import annotations

from decimal import ROUND_HALF_UP, Decimal

from sqlalchemy import and_, case, func, select
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.sql.elements import ColumnElement

from csmarket.modules.orders.api import Order
from csmarket.modules.reviews.cursor import after, decode_rank_cursor, encode_rank_cursor
from csmarket.modules.reviews.models import Review, published
from csmarket.modules.reviews.schemas import PublicReviewOut, PublicReviewsOut
from csmarket.modules.reviews.settings_store import reviews_public
from csmarket.modules.users.api import User

PAGE = 20
_OFF = PublicReviewsOut(enabled=False, count=0, average=None, items=[], next_cursor=None)


def visible() -> ColumnElement[bool]:
    """Published, and its author's account was not deleted."""
    return and_(published(), User.deleted_at.is_(None))


async def published_count(db: AsyncSession) -> int:
    """How many reviews the page shows once it is on."""
    q = select(func.count()).select_from(Review).join(User, User.id == Review.user_id)
    return int(await db.scalar(q.where(visible())) or 0)


def _average(value: Decimal | float | None) -> str | None:
    if value is None:
        return None
    return str(Decimal(value).quantize(Decimal("0.1"), rounding=ROUND_HALF_UP))


async def public_page(db: AsyncSession, *, locale: str, cursor: str | None) -> PublicReviewsOut:
    """Off: :data:`_OFF`. On: the count and average of what is shown, and one page."""
    if not await reviews_public(db):
        return _OFF
    totals = (
        await db.execute(
            select(func.count(), func.avg(Review.rating))
            .select_from(Review)
            .join(User, User.id == Review.user_id)
            .where(visible())
        )
    ).one()
    rank = case((Review.locale == locale, 0), else_=1)
    q = (
        select(Review, User.display_name, User.avatar_url, Order.market_hash_name, rank)
        .join(User, User.id == Review.user_id)
        .outerjoin(Order, Order.id == Review.order_id)
        .where(visible())
    )
    if cursor is not None:
        q = q.where(after(rank, Review.created_at, Review.id, decode_rank_cursor(cursor)))
    q = q.order_by(rank, Review.created_at.desc(), Review.id.desc()).limit(PAGE + 1)
    rows = (await db.execute(q)).all()
    more = len(rows) > PAGE
    rows = rows[:PAGE]
    items = [
        PublicReviewOut(
            id=review.id,
            author_name=name,
            author_avatar_url=avatar,
            rating=review.rating,
            text=review.text,
            kind=review.kind,
            skin_name=skin,
            locale=review.locale,
            created_at=review.created_at,
        )
        for review, name, avatar, skin, _ in rows
    ]
    last = rows[-1] if more else None
    return PublicReviewsOut(
        enabled=True,
        count=int(totals[0]),
        average=_average(totals[1]),
        items=items,
        next_cursor=(
            encode_rank_cursor(int(last[4]), last[0].created_at, last[0].id) if last else None
        ),
    )


__all__ = ["PAGE", "public_page", "published_count", "visible"]
```

```python
from typing import Literal

async def bad_open_count(db: AsyncSession) -> int:
    """Bad reviews no admin has resolved (the menu counter, the gauge)."""
    q = select(func.count()).select_from(Review).where(bad(), Review.resolved_at.is_(None))
    return int(await db.scalar(q) or 0)


def _person(user: User) -> AdminUserOut:
    return AdminUserOut(id=user.id, display_name=user.display_name, avatar_url=user.avatar_url)


def _item(review: Review, number: str, author: User, admin: User | None) -> AdminReviewOut:
    return AdminReviewOut(
        id=review.id,
        kind=review.kind,
        number=number,
        rating=review.rating,
        text=review.text,
        locale=review.locale,
        hidden=review.hidden,
        published=review.rating >= GOOD_FROM and not review.hidden,
        user=_person(author),
        created_at=review.created_at,
        updated_at=review.updated_at,
        resolved_at=review.resolved_at,
        resolved_by=_person(admin) if admin is not None else None,
        resolved_note=review.resolved_note,
    )


def _rank(tab: Tab) -> ColumnElement[int]:
    """«Плохие» puts the unresolved first; the other tabs are one group."""
    if tab == "bad":
        return case((Review.resolved_at.is_(None), 0), else_=1)
    return literal(0, Integer)


def _filters(tab: Tab, kind: str | None, locale: str | None) -> list[ColumnElement[bool]]:
    found: list[ColumnElement[bool]] = []
    if tab == "bad":
        found.append(bad())
    elif tab == "good":
        found.append(Review.rating >= GOOD_FROM)
    if kind is not None:
        found.append(Review.kind == kind)
    if locale is not None:
        found.append(Review.locale == locale)
    return found


async def list_reviews(
    db: AsyncSession, *, tab: Tab, kind: str | None, locale: str | None, cursor: str | None
) -> AdminReviewsPage:
    """One page of a tab, newest first within its groups, :data:`PAGE` a page."""
    author, admin = aliased(User), aliased(User)
    rank = _rank(tab)
    q = (
        select(Review, func.coalesce(Order.number, Sale.number), author, admin, rank)
        .join(author, author.id == Review.user_id)
        .outerjoin(admin, admin.id == Review.resolved_by)
        .outerjoin(Order, Order.id == Review.order_id)
        .outerjoin(Sale, Sale.id == Review.sale_id)
        .where(*_filters(tab, kind, locale))
    )
    if cursor is not None:
        q = q.where(after(rank, Review.created_at, Review.id, decode_rank_cursor(cursor)))
    q = q.order_by(rank, Review.created_at.desc(), Review.id.desc()).limit(PAGE + 1)
    rows = (await db.execute(q)).all()
    more = len(rows) > PAGE
    rows = rows[:PAGE]
    last = rows[-1] if more else None
    return AdminReviewsPage(
        items=[_item(r, n, a, m) for r, n, a, m, _ in rows],
        next_cursor=(
            encode_rank_cursor(int(last[4]), last[0].created_at, last[0].id) if last else None
        ),
        bad_open=await bad_open_count(db),
    )


async def _locked(db: AsyncSession, review_id: str) -> Review:
    """The review under a row lock; 404 ``review_not_found`` for a malformed or unknown id."""
    try:
        uuid.UUID(review_id)
    except ValueError:
        raise NotFoundError("no such review", code="review_not_found") from None
    review = await db.get(Review, review_id, with_for_update=True, populate_existing=True)
    if review is None:
        raise NotFoundError("no such review", code="review_not_found")
    return review


async def _number(db: AsyncSession, review: Review) -> str:
    if review.order_id is not None:
        return str(await db.scalar(select(Order.number).where(Order.id == review.order_id)))
    return str(await db.scalar(select(Sale.number).where(Sale.id == review.sale_id)))


async def _view(db: AsyncSession, review: Review) -> AdminReviewOut:
    author = await db.get_one(User, review.user_id)
    admin = await db.get(User, review.resolved_by) if review.resolved_by else None
    return _item(review, await _number(db, review), author, admin)


async def _audit(db: AsyncSession, review: Review, *, admin_id: str, action: str) -> None:
    await record(
        db,
        actor_id=admin_id,
        action=action,
        target_type="review",
        target_id=review.id,
        payload={"kind": review.kind, "number": await _number(db, review), "rating": review.rating},
    )


async def resolve(db: AsyncSession, *, review_id: str, admin_id: str, note: str) -> AdminReviewOut:
    """«Разобрано»: stamp a bad review handled, once; one already resolved is left as it is.

    Raises:
        NotFoundError: ``review_not_found``.
        ConflictError: ``review_not_bad`` — 4–5 stars need no handling.
    """
    review = await _locked(db, review_id)
    if review.rating >= GOOD_FROM:
        raise ConflictError("only a bad review is resolved", code="review_not_bad")
    if review.resolved_at is None:
        review.resolved_at, review.resolved_by, review.resolved_note = now(), admin_id, note
        await _audit(db, review, admin_id=admin_id, action="reviews.review.resolve")
        await db.flush()
        log.info("reviews.resolved", kind=review.kind, rating=review.rating)
    return await _view(db, review)


async def set_hidden(
    db: AsyncSession, *, review_id: str, admin_id: str, hidden: bool
) -> AdminReviewOut:
    """«Скрыть с сайта» / «Показать»; audited only when it changes. Raises 404."""
    review = await _locked(db, review_id)
    if review.hidden != hidden:
        review.hidden = hidden
        action = "reviews.review.hide" if hidden else "reviews.review.unhide"
        await _audit(db, review, admin_id=admin_id, action=action)
        await db.flush()
    return await _view(db, review)


async def settings_view(db: AsyncSession) -> ReviewSettingsOut:
    """The switch, the count it would show, who set it last."""
    row = await settings_row(db)
    admin = await db.get(User, row.updated_by) if row is not None and row.updated_by else None
    return ReviewSettingsOut(
        reviews_public=row is not None and row.reviews_public,
        published_count=await published_count(db),
        updated_at=row.updated_at if row is not None else None,
        updated_by=_person(admin) if admin is not None else None,
    )


async def save_settings(db: AsyncSession, *, value: bool, admin_id: str) -> ReviewSettingsOut:
    """Set the switch; audited when it changes."""
    row = await settings_row(db)
    was = row is not None and row.reviews_public
    await save_reviews_public(db, value=value, admin_id=admin_id)
    if was != value:
        await record(
            db,
            actor_id=admin_id,
            action="reviews.settings.save",
            target_type="review_settings",
            target_id="1",
            payload={"enabled": value},
        )
        await db.flush()
        log.info("reviews.settings.saved", enabled=value)
    return await settings_view(db)
```

```python
"""Every minute: export the unresolved bad reviews as a gauge (no alert; the admin menu
counts them). The count is ``reviews.bad_open_count``; this job only times it. A failure is
logged and the next tick retries."""

from __future__ import annotations

from apscheduler.schedulers.asyncio import AsyncIOScheduler
from csmarket.core.db import get_session_factory
from csmarket.core.logging import get_logger
from csmarket.core.metrics import set_reviews_bad_open
from csmarket.modules.reviews.api import bad_open_count

from csmarket_scheduler.startup import first_run_after

log = get_logger("csmarket.scheduler.reviews")

JOB_ID = "reviews.bad_open"


async def run() -> None:
    """Count and set the gauge; a failure is logged, not raised."""
    try:
        async with get_session_factory()() as db:
            count = await bad_open_count(db)
        set_reviews_bad_open(count)
    except Exception:
        log.exception("scheduler.reviews.crashed")


def register(scheduler: AsyncIOScheduler) -> None:
    """Every 60 s; first run 460 s after start (≥ 15 s from the other jobs' first runs)."""
    scheduler.add_job(
        run,
        trigger="interval",
        seconds=60,
        id=JOB_ID,
        next_run_time=first_run_after(460),
        replace_existing=True,
        coalesce=True,
        max_instances=1,
    )
```

```ts
/**
 * Reviews (spec 2026-10-23-reviews): wire shapes and calls for `/api/v1/reviews*`, and the
 * rules the prompt follows — good is 4–5 stars, the strip shows once per visit, the modal opens
 * only for a deal that succeeded during this visit.
 */
import { session } from "./api";

export type ReviewKind = "market" | "sale";
export type ReviewLocale = "ru" | "uz" | "en";

/** `DealOut`: the deal the prompt asks about. */
export interface PendingDeal {
  kind: ReviewKind;
  number: string;
  /** The skin's name; a sale's most valuable item. Skin names stay English. */
  title: string;
  image_url: string | null;
  items: number;
  /** When the deal succeeded. */
  done_at: string;
}

/** `MyReviewOut`. */
export interface MyReview {
  rating: number;
  text: string | null;
  locale: string;
  created_at: string;
  updated_at: string;
}

/** `DealReviewOut`. */
export interface DealReview {
  kind: ReviewKind;
  number: string;
  can_review: boolean;
  editable_until: string | null;
  review: MyReview | null;
}

/** `PublicReviewOut`. */
export interface PublicReview {
  id: string;
  author_name: string | null;
  author_avatar_url: string | null;
  rating: number;
  text: string | null;
  kind: ReviewKind;
  skin_name: string | null;
  locale: string;
  created_at: string;
}

/** `PublicReviewsOut`. */
export interface PublicReviews {
  enabled: boolean;
  count: number;
  average: string | null;
  items: PublicReview[];
  next_cursor: string | null;
}

/** `ReviewIn`. */
export interface ReviewIn {
  rating: number;
  text: string | null;
  locale: ReviewLocale;
}

export const GOOD_FROM = 4;
export const TEXT_MAX = 1000;
/** A deal done this long before the page loaded still counts as «this visit» (clock skew). */
export const LIVE_SKEW_MS = 120_000;
const STRIP_KEY = "csmarket.web.review_strip";
// Where the strip's mark lives when the browser refuses sessionStorage: this page load only.
let stripShownHere = false;

export const REVIEW_PENDING_KEY = ["reviews", "pending"] as const;
export const dealReviewKey = (kind: ReviewKind, number: string) =>
  ["reviews", "deal", kind, number] as const;

export const isGood = (rating: number): boolean => rating >= GOOD_FROM;

const path = (kind: ReviewKind, number: string): string =>
  `/api/v1/reviews/${kind}/${encodeURIComponent(number)}`;

/** `GET /reviews/pending`. */
export function getPendingReview(): Promise<{ deal: PendingDeal | null }> {
  return session.apiGet<{ deal: PendingDeal | null }>("/api/v1/reviews/pending");
}

/** `GET /reviews/{kind}/{number}`. */
export function getDealReview(kind: ReviewKind, number: string): Promise<DealReview> {
  return session.apiGet<DealReview>(path(kind, number));
}

/** `PUT /reviews/{kind}/{number}`. */
export function saveReview(
  kind: ReviewKind,
  number: string,
  body: ReviewIn,
  key: string,
): Promise<DealReview> {
  return session.apiPut<DealReview>(path(kind, number), body, { idempotencyKey: key });
}

/** `POST /reviews/{kind}/{number}/snooze` (204). */
export function snoozeReview(kind: ReviewKind, number: string, key: string): Promise<undefined> {
  return session.api<undefined>(`${path(kind, number)}/snooze`, {
    method: "POST",
    idempotencyKey: key,
  });
}

/** `POST /reviews/{kind}/{number}/dismiss` (204). */
export function dismissReview(kind: ReviewKind, number: string, key: string): Promise<undefined> {
  return session.api<undefined>(`${path(kind, number)}/dismiss`, {
    method: "POST",
    idempotencyKey: key,
  });
}

/** `GET /reviews` — a further page of the public list, without a session. */
export function getPublicReviews(locale: ReviewLocale, cursor: string): Promise<PublicReviews> {
  const q = new URLSearchParams({ locale, cursor });
  return session.apiGet<PublicReviews>(`/api/v1/reviews?${q.toString()}`, { anonymous: true });
}

/** A fresh `Idempotency-Key` for one review action. */
export function mintReviewKey(): string {
  return `web-review-${crypto.randomUUID()}`;
}

export interface LiveCheck {
  /** The deal pending when the page loaded (it gets the strip, not the modal). */
  initialNumber: string | null;
  /** Deals the modal was already opened for in this visit. */
  opened: ReadonlySet<string>;
  visitStartMs: number;
}

/** Open the modal for `deal` now: it succeeded during this visit and was not offered yet. */
export function shouldOpenLive(deal: PendingDeal | null, c: LiveCheck): deal is PendingDeal {
  if (deal === null) return false;
  if (deal.number === c.initialNumber || c.opened.has(deal.number)) return false;
  return Date.parse(deal.done_at) >= c.visitStartMs - LIVE_SKEW_MS;
}

/** The strip's turn: `true` the first time in this tab's session, `false` after. */
export function takeStripTurn(): boolean {
  try {
    if (window.sessionStorage.getItem(STRIP_KEY) !== null) return false;
    window.sessionStorage.setItem(STRIP_KEY, "1");
    return true;
  } catch {
    if (stripShownHere) return false;
    stripShownHere = true;
    return true;
  }
}
```

```tsx
"use client";

import { isLocale } from "@csmarket/i18n";
import { Button } from "@csmarket/ui";
import { useMutation, useQueryClient } from "@tanstack/react-query";
import { X } from "lucide-react";
import { useLocale, useTranslations } from "next-intl";
import { useEffect, useId, useRef, useState } from "react";

import { Stars } from "./Stars";

import {
  dealReviewKey,
  isGood,
  mintReviewKey,
  REVIEW_PENDING_KEY,
  saveReview,
  TEXT_MAX,
  type ReviewKind,
} from "@/lib/reviews";

export interface ReviewDeal {
  kind: ReviewKind;
  number: string;
  title: string;
  image_url: string | null;
}

interface ReviewDialogProps {
  deal: ReviewDeal;
  /** A star already chosen (on the strip), or the rating being edited. */
  initialRating?: number | null;
  initialText?: string | null;
  onClose: () => void;
  /** «Не сейчас» (the live prompt and the strip); without it the button is not shown. */
  onLater?: () => void;
}

interface Sent {
  rating: number;
  text: string | null;
}

/**
 * The review modal, mounted only while open: a native `<dialog>` opened with `showModal()`
 * (focus kept inside, Escape and the backdrop close it). The text is sent as typed and never
 * rendered as markup. One `Idempotency-Key` per body, so a retry after a lost answer replays.
 */
export function ReviewDialog({
  deal,
  initialRating = null,
  initialText = null,
  onClose,
  onLater,
}: ReviewDialogProps) {
  const t = useTranslations("web.reviews.prompt");
  const locale = useLocale();
  const qc = useQueryClient();
  const ref = useRef<HTMLDialogElement>(null);
  const titleId = useId();
  const key = useRef<{ body: string; key: string } | null>(null);
  const [rating, setRating] = useState<number | null>(initialRating);
  const [text, setText] = useState(initialText ?? "");

  useEffect(() => {
    const dialog = ref.current;
    if (dialog === null || dialog.open) return;
    // jsdom has no showModal; the attribute keeps the content reachable there.
    if (typeof dialog.showModal === "function") dialog.showModal();
    else dialog.setAttribute("open", "");
  }, []);

  const send = useMutation({
    mutationFn: (body: Sent) => {
      const json = JSON.stringify(body);
      if (key.current?.body !== json) key.current = { body: json, key: mintReviewKey() };
      const lang = isLocale(locale) ? locale : "ru";
      return saveReview(deal.kind, deal.number, { ...body, locale: lang }, key.current.key);
    },
    onSuccess: () => {
      void qc.invalidateQueries({ queryKey: REVIEW_PENDING_KEY });
      void qc.invalidateQueries({ queryKey: dealReviewKey(deal.kind, deal.number) });
    },
  });

  const sent = send.isSuccess ? send.variables : null;
  const title = deal.kind === "market" ? t("titleMarket") : t("titleSale");
  const placeholder =
    rating !== null && !isGood(rating) ? t("placeholderBad") : t("placeholderGood");

  return (
    <dialog
      ref={ref}
      aria-labelledby={titleId}
      onClose={onClose}
      onClick={(e) => {
        if (e.target === e.currentTarget) onClose();
      }}
      className="bg-surface-solid border-border text-fg backdrop:bg-bg/70 m-auto w-[min(480px,calc(100vw-32px))] rounded-2xl border p-0 shadow-[0_24px_60px_rgb(0_0_0/0.5)] backdrop:backdrop-blur-sm"
    >
      <div className="relative flex flex-col items-center gap-4 px-6 pb-7 pt-9 text-center sm:px-8">
        <button
          type="button"
          onClick={onClose}
          aria-label={t("close")}
          className="text-fg-dim hover:text-fg hover:bg-surface-2 focus-visible:ring-accent absolute right-3 top-3 grid size-9 place-items-center rounded-lg focus-visible:outline-none focus-visible:ring-2"
        >
          <X className="size-5" aria-hidden />
        </button>
        {deal.image_url !== null ? (
          // eslint-disable-next-line @next/next/no-img-element -- a Steam CDN image already cut to size
          <img src={deal.image_url} alt="" className="h-24 w-auto object-contain" />
        ) : null}
        <h2 id={titleId} className="text-h3 font-semibold tracking-tight">
          {sent === null ? title : t("thanks")}
        </h2>
        {sent !== null ? (
          !isGood(sent.rating) ? (
            <p className="text-fg-muted">{t("weWillContact")}</p>
          ) : null
        ) : (
          <form
            className="flex w-full flex-col items-center gap-4"
            onSubmit={(e) => {
              e.preventDefault();
              if (rating !== null) send.mutate({ rating, text: text.trim() || null });
            }}
          >
            <Stars value={rating} onChange={setRating} size="lg" />
            <textarea
              aria-label={t("textLabel")}
              value={text}
              maxLength={TEXT_MAX}
              rows={4}
              placeholder={placeholder}
              onChange={(e) => {
                setText(e.target.value);
              }}
              className="border-border bg-bg w-full rounded-lg border p-3 text-base"
            />
            {send.isError ? (
              <p role="alert" className="text-danger text-sm">
                {t("failed")}
              </p>
            ) : null}
            <div className="flex w-full flex-col gap-2 sm:flex-row sm:justify-center">
              <Button type="submit" disabled={rating === null || send.isPending}>
                {t("send")}
              </Button>
              {onLater !== undefined ? (
                <Button variant="ghost" onClick={onLater}>
                  {t("later")}
                </Button>
              ) : null}
            </div>
          </form>
        )}
      </div>
    </dialog>
  );
}
```

```tsx
"use client";

import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { useEffect, useRef, useState } from "react";

import { ReviewDialog } from "./ReviewDialog";
import { ReviewStrip } from "./ReviewStrip";

import { useAuth } from "@/lib/auth";
import {
  dismissReview,
  getPendingReview,
  mintReviewKey,
  REVIEW_PENDING_KEY,
  shouldOpenLive,
  snoozeReview,
  takeStripTurn,
  type PendingDeal,
} from "@/lib/reviews";

type Answer = "snooze" | "dismiss";

/**
 * The site-wide review prompt (spec «Storefront»). The pending deal is read once per page load
 * and again on each socket nudge (`useOrderSocket` invalidates it). The deal pending at load
 * gets the bottom strip, once per visit; a deal that succeeds during the visit opens the modal
 * at once, on whatever page the user is.
 */
export function ReviewPrompt() {
  const { status } = useAuth();
  const qc = useQueryClient();
  const [visitStartMs] = useState(() => Date.now());
  const initial = useRef<{ number: string | null } | null>(null);
  const opened = useRef(new Set<string>());
  const [strip, setStrip] = useState<PendingDeal | null>(null);
  const [modal, setModal] = useState<{ deal: PendingDeal; rating: number | null } | null>(null);
  const pending = useQuery({
    queryKey: REVIEW_PENDING_KEY,
    queryFn: getPendingReview,
    enabled: status === "signed_in",
    staleTime: Infinity,
    retry: false,
  });
  const deal = pending.data?.deal ?? null;

  useEffect(() => {
    if (pending.data === undefined) return;
    if (initial.current === null) {
      initial.current = { number: deal?.number ?? null };
      if (deal !== null && takeStripTurn()) setStrip(deal);
      return;
    }
    const check = { initialNumber: initial.current.number, opened: opened.current, visitStartMs };
    if (shouldOpenLive(deal, check)) {
      opened.current.add(deal.number);
      setStrip(null);
      setModal({ deal, rating: null });
    }
  }, [pending.data, deal, visitStartMs]);

  const answer = useMutation({
    mutationFn: ({ deal: d, verb }: { deal: PendingDeal; verb: Answer }) =>
      (verb === "snooze" ? snoozeReview : dismissReview)(d.kind, d.number, mintReviewKey()),
    onSettled: () => {
      void qc.invalidateQueries({ queryKey: REVIEW_PENDING_KEY });
    },
  });

  return (
    <>
      {strip !== null ? (
        <ReviewStrip
          deal={strip}
          onRate={(rating) => {
            opened.current.add(strip.number);
            setStrip(null);
            setModal({ deal: strip, rating });
          }}
          onLater={() => {
            setStrip(null);
            answer.mutate({ deal: strip, verb: "snooze" });
          }}
          onDismiss={() => {
            setStrip(null);
            answer.mutate({ deal: strip, verb: "dismiss" });
          }}
        />
      ) : null}
      {modal !== null ? (
        <ReviewDialog
          deal={modal.deal}
          initialRating={modal.rating}
          onClose={() => {
            setModal(null);
          }}
          onLater={() => {
            answer.mutate({ deal: modal.deal, verb: "snooze" });
            setModal(null);
          }}
        />
      ) : null}
    </>
  );
}
```

```tsx
import { isLocale } from "@csmarket/i18n";
import { Star } from "lucide-react";
import { hasLocale } from "next-intl";
import { getTranslations, setRequestLocale } from "next-intl/server";

import type { PublicReviews } from "@/lib/reviews";
import type { Metadata } from "next";

import { ComingSoon } from "@/components/ComingSoon";
import { JsonLd } from "@/components/JsonLd";
import { aggregateRating, ReviewList } from "@/components/reviews/ReviewList";
import { ReviewsMore } from "@/components/reviews/ReviewsMore";
import { routing } from "@/i18n/routing";
import { REVIEWS } from "@/lib/paths";
import { alternates, GEO_META, localeUrl, ogLocale, ROBOTS, shareImage } from "@/lib/seo";
import { apiGet } from "@/lib/server-api";

interface Props {
  params: Promise<{ locale: string }>;
}

/** The first page as the API serves it now (5-minute data cache); `null` when it cannot say. */
async function firstPage(locale: string): Promise<PublicReviews | null> {
  try {
    return await apiGet<PublicReviews>(`/reviews?locale=${locale}`, {
      revalidate: 300,
      tags: ["reviews"],
    });
  } catch {
    return null;
  }
}

/** Indexed while the page is on; `noindex` while it is «Скоро» or the API cannot say. */
export async function generateMetadata({ params }: Props): Promise<Metadata> {
  const { locale } = await params;
  const data = await firstPage(locale);
  if (!data?.enabled) {
    const nav = await getTranslations({ locale, namespace: "web.nav" });
    return { title: nav("reviews"), robots: { index: false, follow: true } };
  }
  const t = await getTranslations({ locale, namespace: "web.reviews.page" });
  const title = t("title");
  const description = t("description");
  return {
    title,
    description,
    alternates: alternates(locale, REVIEWS),
    robots: ROBOTS,
    other: GEO_META,
    openGraph: {
      type: "website",
      siteName: "csmarket",
      title,
      description,
      url: localeUrl(locale, REVIEWS),
      ...ogLocale(locale),
      images: shareImage(locale, title).openGraph,
    },
    twitter: shareImage(locale, title).twitter,
  };
}

/** «Отзывы»: «Скоро» while the admin switch is off; the published reviews when it is on. */
export default async function ReviewsPage({ params }: Props) {
  const { locale } = await params;
  if (hasLocale(routing.locales, locale)) {
    // eslint-disable-next-line @typescript-eslint/no-deprecated -- next/root-params needs Next 16; revisit on upgrade
    setRequestLocale(locale);
  }
  const data = await firstPage(locale);
  if (!data?.enabled) return <ComingSoon section="reviews" icon={Star} />;
  const t = await getTranslations("web.reviews.page");
  return (
    <main id="main-content" className="mx-auto flex max-w-[960px] flex-col gap-4 px-4 py-8 sm:px-6">
      {data.average !== null ? <JsonLd data={aggregateRating(data)} /> : null}
      <h1 className="text-h2 font-semibold tracking-tight">{t("heading")}</h1>
      <p className="text-fg-muted">
        {data.average !== null
          ? t("summary", { average: data.average, count: data.count })
          : t("empty")}
      </p>
      <ReviewList items={data.items} locale={locale} />
      {data.next_cursor !== null ? (
        <ReviewsMore locale={isLocale(locale) ? locale : "ru"} cursor={data.next_cursor} />
      ) : null}
    </main>
  );
}
```

```ts
/** Admin reviews API (spec 2026-10-23-reviews): `/api/v1/admin/reviews*`. Mirrors the API. */
import { session } from "@/lib/api";

export type ReviewTab = "bad" | "all" | "good";
export type ReviewKind = "market" | "sale";
export type ReviewLocale = "ru" | "uz" | "en";

export interface ReviewUser {
  id: string;
  display_name: string | null;
  avatar_url: string | null;
}

export interface AdminReview {
  id: string;
  kind: ReviewKind;
  number: string;
  rating: number;
  text: string | null;
  locale: ReviewLocale;
  hidden: boolean;
  published: boolean;
  user: ReviewUser;
  created_at: string;
  updated_at: string;
  resolved_at: string | null;
  resolved_by: ReviewUser | null;
  resolved_note: string | null;
}

export interface ReviewsPage {
  items: AdminReview[];
  next_cursor: string | null;
  /** Unresolved bad reviews, whatever the tab and filters. */
  bad_open: number;
}

export interface ReviewSettings {
  reviews_public: boolean;
  published_count: number;
  updated_at: string | null;
  updated_by: ReviewUser | null;
}

export interface ReviewFilter {
  tab: ReviewTab;
  kind: ReviewKind | "";
  locale: ReviewLocale | "";
}

const BASE = "/api/v1/admin/reviews";

export function getReviews(f: ReviewFilter, cursor: string | null): Promise<ReviewsPage> {
  const q = new URLSearchParams({ tab: f.tab });
  if (f.kind !== "") q.set("kind", f.kind);
  if (f.locale !== "") q.set("locale", f.locale);
  if (cursor !== null) q.set("cursor", cursor);
  return session.apiGet<ReviewsPage>(`${BASE}?${q.toString()}`);
}

export const resolveReview = (id: string, note: string, key: string): Promise<AdminReview> =>
  session.apiPost<AdminReview>(
    `${BASE}/${encodeURIComponent(id)}/resolve`,
    { note },
    { idempotencyKey: key },
  );

export const setReviewHidden = (id: string, hidden: boolean, key: string): Promise<AdminReview> =>
  session.apiPost<AdminReview>(
    `${BASE}/${encodeURIComponent(id)}/${hidden ? "hide" : "unhide"}`,
    {},
    { idempotencyKey: key },
  );

export const getReviewSettings = (): Promise<ReviewSettings> =>
  session.apiGet<ReviewSettings>(`${BASE}/settings`);

export const saveReviewSettings = (on: boolean, key: string): Promise<ReviewSettings> =>
  session.apiPut<ReviewSettings>(
    `${BASE}/settings`,
    { reviews_public: on },
    { idempotencyKey: key },
  );
```

```tsx
/** «Показывать отзывы на сайте»: the public page's switch, with what it would show. */
import { Button, Switch } from "@csmarket/ui";
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { useState } from "react";

import { getReviewSettings, type ReviewSettings, saveReviewSettings } from "./api";

import { CONFIRM_BUTTONS, ConfirmSheet } from "@/components/ConfirmSheet";
import { Section } from "@/components/Section";
import { errorText } from "@/features/users/labels";
import { useIdempotencyKey } from "@/features/users/useIdempotencyKey";

export const SETTINGS_KEY = ["admin", "reviews", "settings"] as const;

export function ReviewsSettings() {
  const qc = useQueryClient();
  const q = useQuery({ queryKey: SETTINGS_KEY, queryFn: getReviewSettings });
  const key = useIdempotencyKey("admin-reviews-settings");
  const [confirming, setConfirming] = useState(false);
  const save = useMutation({
    mutationFn: (on: boolean) => saveReviewSettings(on, key.keyFor(String(on))),
    onSuccess: (data: ReviewSettings) => {
      key.reset();
      setConfirming(false);
      qc.setQueryData(SETTINGS_KEY, data);
    },
  });
  if (q.data === undefined) return null;
  const s = q.data;
  return (
    <Section title="Страница отзывов">
      <Switch
        label="Показывать отзывы на сайте"
        checked={s.reviews_public}
        disabled={save.isPending}
        hint={`Опубликовано: ${String(s.published_count)}`}
        onCheckedChange={(on) => {
          if (on) setConfirming(true);
          else save.mutate(false);
        }}
      />
      {save.isError ? (
        <p role="alert" className="text-danger text-sm">
          {errorText(save.error)}
        </p>
      ) : null}
      {confirming ? (
        <ConfirmSheet
          title="Включить страницу отзывов?"
          busy={save.isPending}
          onClose={() => {
            setConfirming(false);
          }}
        >
          <p className="font-medium">
            На csmarket.uz/reviews появятся опубликованные отзывы: {s.published_count}. Плохие и
            скрытые не показываются.
          </p>
          <div className={CONFIRM_BUTTONS}>
            <Button
              variant="ghost"
              onClick={() => {
                setConfirming(false);
              }}
            >
              Отмена
            </Button>
            <Button
              onClick={() => {
                save.mutate(true);
              }}
            >
              Включить
            </Button>
          </div>
        </ConfirmSheet>
      ) : null}
    </Section>
  );
}
```

```tsx
 * filters by kind and language; the public page's switch on top.
 */
import { Button } from "@csmarket/ui";
import { type InfiniteData, useInfiniteQuery, useQueryClient } from "@tanstack/react-query";

import { getReviews, type ReviewFilter, type ReviewsPage as Page } from "./api";
import { KIND_LABELS, KINDS, LOCALE_LABELS, LOCALES, TAB_LABELS, TABS } from "./labels";
import { ReviewRow } from "./ReviewRow";
import { ReviewsSettings } from "./ReviewsSettings";

import { EmptyState } from "@/components/EmptyState";
import { FilterSelect, FiltersBar } from "@/components/Filters";
import { PageHeader } from "@/components/PageHeader";
import { Tabs } from "@/components/Tabs";
import { DASHBOARD_KEY } from "@/features/dashboard/keys";
import { errorText } from "@/features/users/labels";
import { pick } from "@/lib/url-guards";
import { useUrlParams } from "@/lib/useUrlParams";

const LIST_KEY = ["admin", "reviews", "list"] as const;

export function ReviewsPage() {
  const url = useUrlParams();
  const qc = useQueryClient();
  const filter: ReviewFilter = {
    tab: pick(TABS, url.get("tab")) ?? "bad",
    kind: pick(KINDS, url.get("kind")) ?? "",
    locale: pick(LOCALES, url.get("locale")) ?? "",
  };
  const list = useInfiniteQuery<
    Page,
    Error,
    InfiniteData<Page, string | null>,
    readonly unknown[],
    string | null
  >({
    queryKey: [...LIST_KEY, filter],
    queryFn: ({ pageParam }) => getReviews(filter, pageParam),
    initialPageParam: null,
    getNextPageParam: (last) => last.next_cursor,
  });
  const pages = list.data?.pages;
  const items = pages?.flatMap((p) => p.items) ?? [];
  const badOpen = pages?.[0]?.bad_open;
  const refresh = () => {
    void qc.invalidateQueries({ queryKey: LIST_KEY });
    void qc.invalidateQueries({ queryKey: DASHBOARD_KEY });
  };

  return (
    <section className="space-y-4">
      <PageHeader title="Отзывы" />
      <ReviewsSettings />
      <Tabs
        label="Отзывы"
        value={filter.tab}
        onChange={(v) => {
          url.set("tab", v === "bad" ? "" : v);
        }}
        items={TABS.map((key) => ({
          key,
          label: TAB_LABELS[key],
          ...(key === "bad" && badOpen !== undefined && { count: badOpen, alert: true }),
        }))}
      />
      <FiltersBar>
        <FilterSelect
          label="Тип"
          value={filter.kind}
          options={KINDS}
          text={(k) => KIND_LABELS[k]}
          onChange={(v) => {
            url.set("kind", v);
          }}
        />
        <FilterSelect
          label="Язык"
          value={filter.locale}
          options={LOCALES}
          text={(l) => LOCALE_LABELS[l]}
          onChange={(v) => {
            url.set("locale", v);
          }}
        />
      </FiltersBar>
      {list.isError ? <EmptyState tone="danger">{errorText(list.error)}</EmptyState> : null}
      {list.isSuccess && items.length === 0 ? <EmptyState>Отзывов нет.</EmptyState> : null}
      <ul className="flex flex-col gap-2">
        {items.map((r) => (
          <ReviewRow key={r.id} review={r} onChanged={refresh} />
        ))}
      </ul>
      {list.hasNextPage ? (
        <Button
          variant="secondary"
          disabled={list.isFetchingNextPage}
          onClick={() => {
            void list.fetchNextPage();
          }}
        >
          Показать ещё
        </Button>
      ) : null}
    </section>
  );
}
```

  95 % gate and the docs list (T7).
- **Rulings on what the spec leaves open** (also in ADR-0023):
  1. `GET /reviews/{kind}/{number}` (my review of one deal) and `GET /admin/reviews/settings` are
     added — the account slot and the switch's count need a read.
  2. Partner-API orders (`channel = 'api'`) are not reviewable: the «user» is a bot's key owner.
  3. A changed review that stays bad is reopened, not only good → bad (a resolved complaint the
     user rewrites must reach an admin again); an unchanged re-send keeps the resolution.
  4. «404-like empty» = 200 with `enabled: false` and nothing else, so the storefront renders
     «Скоро» without an error path.
  5. The switch lives in its own singleton `review_settings` (the repo has no shared key-value
     settings store; `sale_settings` / `payment_settings` are per-module singletons too).
  6. Reviews of a deleted account (`users.deleted_at`) are not shown or counted.
  7. A sale's picture and name in the prompt are its most valuable item's.
  8. Snooze / dismiss of a deal outside rule 7 is 409 like a write; closing the modal with × /
     Escape only closes it (no server call) — only «Не сейчас» snoozes.
- **Spec gaps flagged for the owner.** The public average is over published reviews only (all
  4–5), so it is always ≥ 4.0 — truthful to what the page lists, but Google does not show
  self-serving `AggregateRating` as a rich result; the markup is harmless, not a ranking lever.
  No account-deletion flow exists yet, so nothing erases a user's review text on request — the
  PII inventory notes it.
- **Type consistency.** `Kind` / `KindOut` = `"market" | "sale"` across `deals.py`, `schemas.py`,
  routes and both TS clients; `REVIEW_PENDING_KEY` defined in T8, used in T9 (`useOrderSocket`,
  `ReviewPrompt`) and T8's dialog; `dealReviewKey` in T8, T10; `bad_open_count` in T5, re-exported
  by `reviews.api` in T6 for the dashboard and the scheduler; `PAGE` constants monkeypatched by
  name in T5.
