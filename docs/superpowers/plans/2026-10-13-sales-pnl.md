# Skin-sales P&L and Skinslink reconciliation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A «Выкуп» P&L block on the admin dashboard and a «Сверка» page listing each sale's
quoted vs credited Skinslink amount.

**Architecture:** Everything is read from `sales`, `payout_requests` and `fx_snapshots`; no
Skinslink call. A pure module `sales/pnl.py` turns one sale row into income and costs; a query
module `sales/pnl_query.py` loads the window's rows and aggregates them for the dashboard and
the reconciliation page. One new setting (`bank_fee_pct`) and one new column
(`payout_requests.bank_fee_uzs`, written at «Выплачено»).

**Tech Stack:** FastAPI, SQLAlchemy 2 async, Alembic, Pydantic v2; React 19 + TanStack Query
in `apps/admin`.

**Spec:** `docs/superpowers/specs/2026-10-13-sales-pnl-design.md`

## Global Constraints

- Money is `Decimal`; soʻm whole units, USD six decimals; on the wire as strings.
- Tashkent days: the window is `orders.dashboard.window_start(at, days)`; days are 1, 7, 30.
- `bank_fee_pct`: default `1`, bounds 0–10, two decimals.
- `bank_fee_uzs = ceil(amount_uzs × bank_fee_pct / 100)`; cleared by an undo of «Выплачено».
- USD conversion of soʻm costs: the newest `fx_snapshots.usd_uzs` at or before
  `sales.created_at`; none → the sale's own `rate`.
- Flags: `short` = `amount_usd < quoted_usd × 0.99`; `missing` = status `credited`/`payout` and
  `amount_usd` null; `reverted` = `attention_reason` in (`rolled_back`, `late_deposit`).
- check-no-yupay: no «supplier» in `src`. No PII in logs.
- The `sales` module keeps ≥ 95 % coverage.

## Review Focus

1. A card sale whose request was **rejected** costs `items_uzs` (credited to balance), not the
   card amount — test in Task 2.
2. A sale **rolled back after payout** has zero income and keeps its cost (a loss) — Task 2.
3. A sale credited at **23:30 Tashkent** counts on that Tashkent day — Task 3.
4. A `paid` request **from before the column** (null `bank_fee_uzs`) uses the current
   setting — Task 2.
5. A window with **no sales** gives zeros, never a division by zero in the percent — Task 2.

def bank_fee(amount_uzs: Decimal, pct: Decimal) -> Decimal:
